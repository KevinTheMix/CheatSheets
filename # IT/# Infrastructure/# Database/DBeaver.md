## Shortcuts

* `F3` = open SQL script (à la `Alt + Tab`, or create new)
* `Ctrl + ]` = new script
* `Ctrl + W` = close tab
* `Ctrl + Enter` = execute SQL query
* `Ctrl + Alt + Up/Down` = clone current line up/down
* `Ctrl + Page Up/Down` = navigate to previous/next tab
