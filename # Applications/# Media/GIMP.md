# GIMP

GNU Image Manipulation Program

## Quick Tips

* When adding transparency to an existing image, make sure image has a format that handles alpha (ie not an Indexed colors, which typically doesn't support alpha transparency, and must be converted to a RGB)

## Glossary

## Commands

* *Layer*
  * *Transparency → Add Alpha Channel*
  * *Duplicate Layer*
* *Selection*
  * *None*
  * *Grow*

## Shortcuts

* `/` = Search Actions
* `B` = Paths Tool
  * Click on last vertice to join to next one
  * `Ctrl + Click` to join vertices
* `Middle-Click` = pan
* `Ctrl + E` = Export (to PNG, etc)
* `Ctrl + I` = Invert selection
* `Ctrl + Shift + A` = Deselect
* `Shift + B` = Bucket Fill Tool (*Fill whole selection*)
* `Shift + O` = Select by Color Tool (play with *Threshold*)
* `Shift + V` = Select From Path
